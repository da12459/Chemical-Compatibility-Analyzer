## Software Availability Statement

The Chemical Compatibility Analyzer (version 0.1.0) is publicly available as a Windows executable through GitHub (https://github.com/da12459/Chemical-Compatibility-Analyzer). The corresponding software release is archived on Zenodo (https://doi.org/10.5281/zenodo.23491523).

The software is distributed under the Chemical Compatibility Analyzer Freeware License, with copyright held by Xiangjuan Qi. The complete source code of the computational engine is not included in the current release.

The software supports preliminary chemical compatibility screening through chemical name/CAS retrieval, MOL-file import, automated reactive-group identification, optional manual category adjustment, and compatibility calculations based on an established 68-category reactive-group compatibility matrix.

## Evaluation Data

The associated research describes 90 chemical-contact cases compiled from publicly accessible reports and literature.

For these cases, the software automatically identified reactive-group categories and subsequently performed compatibility analysis. The reported results comprise 81 "Incompatible" and 9 "Caution Required" alerts.

The evaluation demonstrates the implementation of an integrated workflow from chemical information input and automated reactive-group assignment to compatibility calculation and result generation.

These results should not be interpreted as an independently established identification accuracy rate or as quantitative predictions of chemical reaction consequences.

Detailed chemical identities, assigned reactive-group categories, compatibility results, and supporting literature sources should be documented in the Supporting Information accompanying the manuscript.

## Scope and Limitations

The software provides preliminary qualitative chemical compatibility screening and does not replace experimental verification, chemical-specific hazard assessment, or professional process safety review.

A "Compatible" screening result does not guarantee that chemical mixing, processing, or storage is safe.

The current executable release is publicly accessible but does not constitute a complete open-source software distribution.
